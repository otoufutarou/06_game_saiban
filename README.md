# 06_game_saiban

## 天国審査（仮題）

ブラウザーだけで遊べる、全5回の報告書審査ゲームです。各回の3人から1人を天国へ、残る2人を地獄へ送ります。判定の採点や正解はありません。人物情報は同梱の最終版JSONをそのまま読み込みます。

### 起動

このディレクトリで `python3 -m http.server 8000` を実行し、ブラウザーで `http://localhost:8000` を開いてください。ビルド、追加パッケージ、ログイン、音声はありません。`file://` ではJSONの読み込みが制限されるためHTTPで起動してください。

### 操作と保存

- タップ・クリック、またはTabで移動しEnter / Spaceで操作します。確認画面はEscapeまたは「いいえ」で取り消せます。
- チュートリアルの会話中は画面内のどこでもタップできます。文字送り中は全文を表示し、全文表示後は次のセリフへ進みます。通常の審査・結果画面では全画面タップによる進行は行いません。
- 画像内の矢印・左右の小さな報告書で候補者を切り替え、中央の報告書内をスクロールして全文を読めます。人物ごとのスクロール位置は切り替え・再開時にも復元します。閲覧と選択は独立しており、下部の氏名は天国行きの確認を開きます。「いいえ」では閲覧位置も選択結果も変更しません。
- チュートリアルの位置、審査回、表示中の候補者、人物ごとの詳細スクロール位置、確定した選択、現在の画面を同じブラウザーのlocalStorageに自動保存します。
- 報告書のスクロール位置はフォントの読込完了後に復元します。スクロール保存は描画フレームごとにまとめ、ページを隠す・閉じる際にも未保存分を反映します。
- 確認画面を開いただけでは判定は確定しません。「はい」で結果をアニメーション前に保存します。一度確定した審査には戻れません。
- 再読み込み後はタイトルの「つづきから」で再開します。既存の保存がある「はじめから」には上書き確認があります。
- 保存が壊れている場合は続行を無効にし、新しく開始できます。保存禁止・容量不足の場合も遊べますが、閉じると進行が失われる可能性を画面に通知します。ブラウザーのデータ消去でも保存は失われます。

### 表示と素材

タイトル・導入・通常審査は941×1672、各回完了は864×1536の実寸座標を使用します。背景と前面UIを同じ座標系で拡大縮小し、タイトル・導入では上下の装飾部分を最大180座標分だけ切り取って画面幅に合わせます。それ以上切り取る必要がある画面では、タイトルや吹き出しを守るため全体を収めます。支給PNGは加工せず、文字・ボタンはHTMLです。

正式背景はタイトル・導入に `無題49_20261025213512.png`、通常審査に `無題48_20261025213530.png`、各回の審査完了と審判終了画面に `無題50_20261025214014.png` を使用します。10月26日の `無題49_20261026101213.png`・`無題48_20261026101439.png`・`無題50_20261026101611.png` は配置参考であり、実行時には読み込みません。文字消去・画像の加工も行いません。

確認は通常審査を暗くするHTMLのモーダルです。「はい」で確定・保存してから完了画面へ進みます。タイトルから導入へは背景を変えず、上部吹き出しだけを50ms／文字で更新します。導入中の下部欄は操作説明となり、開始・再開メニューはありません。画面間のみ水色のドット遷移を使用します。

矢印は画像内の絵柄をそのまま使用し、透明な `.arrow.left`（x25、y798、100×128）と `.arrow.right`（x835、y798、100×128）を941×1672座標に配置します。候補者名は表示専用で、切り替えは画像内矢印のタップ領域だけで行います。中央報告書のスクロール領域（x165、y420、630×795）とは重なりません。上部の審査名・回数プレートは表示しません。

第5回の「審判を終える」後は既存の仮終了表示を維持しています。最終リザルト画像 `無題43_20261025190904.png` の画面・集計バックエンドは未実装で、架空の割合は表示しません。旧素材・参考画像はリポジトリに保存されていますが、正式背景以外をゲームの背景として使用しません。

フォントはKHドット兜町16（KH Dot Kabutochou 16）。`fonts/README_KHDotFont.txt` と `fonts/SIL_Open_Font_License_1.1.txt` に原著作権表示・OFL 1.1ライセンスを同梱しています。フォント読込失敗や未収録文字は画面下部に通知し、ゲームの開始を停止します。診断画面のボタンで再読み込みして再試行できます。許可なく代替フォントに切り替えることはありません。診断メッセージのみ端末フォントを使用します。

### 検証範囲

既存のテスト・ビルド・lint環境はありません。`node --check game.js` による構文検証とローカルHTTP上のブラウザー操作で検証できます。実機の全ブラウザー、端末フォント、プライベートモードやストレージ容量制限の全組合せは保証できません。

実装時にはHeadless Chromium 155で全15人の原文・セクション順、全5回の進行、再開、詳細スクロール復元、確認取り消し、確定直後の再読み込み、上書き確認、破損保存の拒否、保存不可、フォント取得失敗時の開始停止と再試行、データ取得失敗からの復旧、縦横5種類の画面サイズを検証しました。
